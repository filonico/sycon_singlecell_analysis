# Re-analysis of the *Spongilla lacustris* single-cell atlas: intermediate results

This folder contains several intermediate results generated with the re-analysis of the *S. lacustris* single-cell dataset (Musser et al., 2021; [10.1126/science.abj2949](https://doi.org/10.1126/science.abj2949)), following read mapping to the genome assembly [GCA_949361645.1](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_949361645.1/) (Leys et al., 2025; [10.12688/wellcomeopenres.23988.1](https://doi.org/10.12688/wellcomeopenres.23988.1)).

## Repository content
The repository contains the following:

| Directory/File | Description |
| --- | --- |
| [`01_spongilla_Sobjects_umaps/`](./01_spongilla_Sobjects_umaps/) | Seurat objects, marker genes, and plots generated from the single cell analysis. |
| [`02_integration_with_old_dataset/`](./02_integration_with_old_dataset/) | Integration check with the original single cell dataset mapped to the transcriptome. |
| [`README.md`](./README.md) | This file. |
