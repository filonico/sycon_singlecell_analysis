# Re-analysis of the *Spongilla lacustris* single-cell atlas: input files

This folder contains several files that are needed as input for re-analysis of the *S. lacustris* single-cell dataset (Musser et al., 2021; [10.1126/science.abj2949](https://doi.org/10.1126/science.abj2949)), following read mapping to the genome assembly [GCA_949361645.1](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_949361645.1/) (Leys et al., 2025; [10.12688/wellcomeopenres.23988.1](https://doi.org/10.12688/wellcomeopenres.23988.1)).

| Directory/File | Description |
| --- | --- |
| [`README.md`](./README.md) | This file. |
| [`SRA_toDownload.ls`](./SRA_toDownload.ls) | List of SRA files of single-cell reads. |
| [`SRA_toDownload.tsv`](./SRA_toDownload.tsv) | Metadata of SRA files of single-cell reads. |
| [`slac_genome.tar.gz`](./slac_genome.tar.gz) | Genome assembly and annotation. |
| [`slac_transcriptome.tar.gz`](./slac_transcriptome.tar.gz) | Assembled transcriptome. |
| [`spongilla_marker_genes.tsv`](./spongilla_marker_genes.tsv) | Some *Spongilla* marker genes useful to annotate cell types. |
