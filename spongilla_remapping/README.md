# Re-analysis of the *Spongilla lacustris* single-cell atlas

This folder contains all the scripts and data used to re-analyse the *S. lacustris* single-cell dataset (Musser et al., 2021; [10.1126/science.abj2949](https://doi.org/10.1126/science.abj2949)) following read mapping to the genome assembly [GCA_949361645.1](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_949361645.1/) (Leys et al., 2025; [10.12688/wellcomeopenres.23988.1](https://doi.org/10.12688/wellcomeopenres.23988.1)).

## Repository content
The repository contains the following:
| Directory/File | Description |
| --- | --- |
| [`00_input/`](./00_input/) | Several files that are needed as input for the analyses. |
| [`conda_envs/`](./conda_envs/) | YAML files of the conda environments used to run the analyses. |
| [`intermediate_results/`](./intermediate_results/) | Several intermediate results generated by the analyses. |
| [`scripts/`](./scripts/) | Scripts used to run the analyses. |
| [`README.md`](./README.md) | This file. |
| [`pipeline.sh`](./pipeline.sh) | Code documentation and script execution. |

Where relevant, additional `README.md` files are available within the subderectories.
