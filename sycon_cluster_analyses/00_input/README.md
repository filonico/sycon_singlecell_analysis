# *Sycon ciliatum* single-cell cluster analyses: input files

This folder contains several files that are needed as input for the analyses of the *S. ciliatum* single-cell dataset.

## Repository content
The repository contains the following:
| Directory/File | Description |
| --- | --- |
| [`Aque_protein.faa.tar.gz`](./Scil_protein.faa.tar.gz) | Annotated protein from the *Amphimedon queenslandica* genome, as obtained from source publication (Srivastava et al., 2010; [10.1038/nature09201](https://doi.org/10.1038/nature09201)). |
| [`Scil_protein.faa.tar.gz`](./Scil_protein.faa.tar.gz) | Annotated protein from the *S. ciliatum* genome, as produced in this work. |
| [`Slac_protein.faa.tar.gz`](./Slac_protein.faa.tar.gz) | Annotated protein from the *Spongilla lacustris* genome, as obtained from source publication (Leys et al., 2025; [10.12688/wellcomeopenres.23988.1](https://doi.org/10.12688/wellcomeopenres.23988.1)). |
| [`cell_cycle_markers.tar.gz`](./cell_cycle_markers.tar.gz) | Cell cycle canonical markers as obtained from [github.com/hbc/tinyatlas/tree/master/cell_cycle](https://github.com/hbc/tinyatlas/tree/master/cell_cycle) on 23/01/2025. |
| [`slac_genome_genename_conversion.ls`](./slac_genome_genename_conversion.ls) | Several intermediate results generated by the analyses. |
| [`species_metadata.tsv`](./species_metadata.tsv) | Scripts used to run the analyses. |

Where appropriate, additional `README.md` files are available within the subderectories.
