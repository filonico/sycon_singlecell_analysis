# *Sycon ciliatum* single-cell analysis intermediate results

This folder contains several intermediate results generated by the analyses of the *S. ciliatum* single-cell dataset.

## Repository content
The repository contains the following:
| Directory/File | Description |
| --- | --- |
| [`01_sycon_Sobjects/`](./01_sycon_Sobjects/) | Sycon main `Rds` objects, and lookup table for cluster identity.  |
| [`02_SAMap_porifera/`](./02_SAMap_porifera/) | SAMap `h5ad` integrated objects, and several stats (mapping scores, gene pairs, etc.).  |
| [`03_all_markers_per_cluster/all_markers*`](./03_all_markers_per_cluster/) | Full tables with expression statistics for every analysed gene in every cluster. |
| [`03_all_markers_per_cluster/upregulated*`](./03_all_markers_per_cluster/) | Lists of upregulated markers per cluster (log2FC > 0; p_val_adj < 0.05). |
| [`04_gene_annotation/`](./04_gene_annotation/) | Proteome InterPro annotation, as well as GO and KO terms. |
| [`05_hdWGCNA_modules/`](./05_hdWGCNA_modules/) | hdWGCNA `Rds` object, and lists of genes making up each co-expression module. |
